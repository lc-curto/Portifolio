Um pouco sobre mim

Sou Lucas Curto, estudante de Desenvolvimento de Software, com interesse em criar aplicações web e sistemas de gestão.

Tenho conhecimentos de HTML e CSS e estou a desenvolver competências em C# e .NET, através de exercícios práticos e projetos pessoais. Estou também a explorar tecnologias como Python, FastAPI, React e TypeScript.

Entre os meus projetos, destaco o Distribution Hub, uma plataforma de gestão comercial em desenvolvimento, com uma API e uma aplicação web.

Ao longo da minha formação, quero aprofundar conhecimentos em bases de dados, programação orientada a objetos, desenvolvimento web, APIs e qualidade de software.
